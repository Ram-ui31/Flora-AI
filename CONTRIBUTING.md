# Contributing

Create a Python virtual environment and install `requirements-dev.txt`. Run `python -m pytest -q` before submitting changes.

Keep changes focused and describe the behavior, validation, and any limitations. For frontend changes, check desktop/mobile layouts, home/studio navigation, instrument selection, playback, uploads, and pitch/reset behavior. For model or streaming changes, include a reproducible test or measurement.

Do not commit datasets, audio recordings, checkpoints, credentials, or machine-specific manifests. Preserve upstream attribution and third-party notices. Keep benchmark evidence distinct from results generated by a new experiment.
